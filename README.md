# KORI - Your money, in control.

Projet réalisé dans le cadre du challenge LibraryUI (https://libraryui.com/challenges/cree-une-interface-avec-des-composants-de-libraryui) , réalisé en Angular à partir des composants préts à l'emploi de LibraryUI. 

```bash
npm install --legacy-peer-deps
npm start
```

## Composants LibraryUI

**Composant carte** — Modèle utilisé : Event Card  
https://libraryui.com/components/tailwind/cards-tw?category=all&page=2&search=

**Composant table** — Modèle utilisé : Dataset  
https://libraryui.com/components/tailwind/data-table-tw?category=all&page=3&search=

**Composant Dropdown** — Modèle utilisé : account menu dropdown  
https://libraryui.com/components/tailwind/dropdown-tw?category=all&page=3&search=

**Composant Dashboard** — Modèle utilisé : E-learning  
https://libraryui.com/components/tailwind/dashboard-e-learning-tw?category=all&page=3&search=

**Composant cookie** — Modèle utilisé : V3  
https://libraryui.com/components/tailwind/cookies-tw?category=all&page=1&search=cookie

**Composant confirmation** — Modèle utilisé : Toast  
https://libraryui.com/components/tailwind/confirmation-tw?category=all&page=1&search=conf
